PACKAGE OVERVIEW:
  Package : classiccompare
  Version : 0.0.0.9000
  Author  : Sharang Nimonkar
  License : MIT
  R Version: >= 4.5.3 (tested on R 4.5.3, Windows 11 x64)

  Compares a base and a comparison data frame and reports differences
  in variables, observations and values, in the style of the SAS
  dataset comparison utility (PROC COMPARE). Observations can be
  matched by position, ID or BY variables. Values are compared
  exactly or with absolute, relative or percent criteria, with
  optional FUZZ tolerance. A bitmask return code (SYSINFO) supports
  automated quality control checks in regulated / clinical workflows.

HOW TO LOAD AND USE:
------------------------------------------------------------------------

  library(classiccompare)

  base <- data.frame(id = c("A", "B", "C"), x = c(1, 2, 3), y = c("a", "b", "c"))
  comp <- data.frame(id = c("C", "A", "D"), x = c(3, 1.5, 9), y = c("c", "a", "d"))

  # Full comparison report, matched by ID
  res <- classic_compare(base, comp, id = "id", listall = TRUE)
  res

  # Bitmask return code for automated QC checks
  sysinfo(res)                  # e.g. 4288
  sysinfo_decode(sysinfo(res))  # "BASEOBS" "COMPOBS" "VALUE"

  # Tolerance-based comparison
  classic_compare(data.frame(x = 100), data.frame(x = 100.4),
                  method = "percent", criterion = 0.5)

  # Compare only specific variables (VAR / WITH)
  classic_compare(base, comp, id = "id", var = "x")

  # Structure-only comparison, no value comparison (NOVALUES)
  classic_compare(base, comp, id = "id", novalues = TRUE, listall = TRUE)

  vignette("classiccompare", package = "classiccompare")   # full worked example
