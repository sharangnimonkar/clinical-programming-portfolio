Introduction to classiccompare

library(classiccompare)

Basic comparison

classic_compare() compares two data frames the way SAS’s PROC COMPARE compares two datasets. With no id or by, observations are matched by row position:

base <- data.frame(id = c("A", "B", "C"), x = c(1, 2, 3), y = c("a", "b", "c"))
comp <- data.frame(id = c("C", "A", "D"), x = c(3, 1.5, 9), y = c("c", "a", "d"))

classic_compare(base, comp)

Return code for QC scripts

res <- classic_compare(base, comp, id = "id")
sysinfo(res)
#> [1] 4288
sysinfo_decode(sysinfo(res))
#> [1] "BASEOBS" "COMPOBS" "VALUE"
stopifnot_example <- tryCatch(
  stopifnot(sysinfo(res) == 0L),
  error = function(e) "datasets differ — this would normally halt a QC script"
)
stopifnot_example
#> [1] "datasets differ — this would normally halt a QC script"
